# The Long Roast: Lawmakers and the File They Cannot Convert

A make.fun bounty entry. `main.py` (Python 3, stdlib only, no network) writes
a single original sentence — a long, funny roast of lawmakers who would
regulate AI, crypto or the internet but cannot convert a file to PDF — to
`/output/entry.txt`:

> They can write a 400-page bill regulating artificial intelligence in a morning, yet by lunch they are still emailing their intern a crooked photo of a Word document and asking her to please make it a PDF.

The line is 204 characters, deterministic, and validated before writing
(non-empty, single line, exactly one sentence, within the 320-character limit).
